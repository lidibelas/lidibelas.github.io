# Contribuindo com o site

Obrigada pelo interesse em contribuir! Este é o site acadêmico pessoal de **Lídia Belas**.

## Como sugerir uma melhoria

1. **Abra uma Issue** descrevendo o que você notou (bug, sugestão, correção de informação)
2. Se for correção simples (link quebrado, erro de digitação), você pode:
   - Abrir um Pull Request diretamente, ou
   - Apenas descrever na Issue
3. Aguarde resposta — o repo é mantido por uma pessoa só, então pode demorar alguns dias

## O que é bem-vindo

- 🐛 Correção de bugs (links quebrados, layout quebrado em algum navegador)
- 🌐 Melhorias de tradução (PT → EN, ES)
- 📝 Correções de informação (datas erradas, links desatualizados)
- ♿ Sugestões de acessibilidade

## O que NÃO é bem-vindo

- Mudanças no design sem discussão prévia (abra Issue primeiro)
- Alterações em dados pessoais sem autorização
- Qualquer conteúdo que não esteja relacionado ao site acadêmico

## Estilo de commits

- Mensagens curtas e em inglês quando possível
- Prefixo: `fix:`, `style:`, `content:`, `i18n:`, `docs:`

Dúvidas? Abra uma Issue ou entre em contato.
